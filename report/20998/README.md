Όσο ο άνθρωπος τροφοδοτεί με γνώσεις τον υπολογιστή, τόσο ο υπολογιστής λειτουργεί, στην αρχή υποστηρικτικά και ίσως κάποια μέρα καθολικά, ώστε να βελτιώσει και επιταχύνει την ανθρώπινη εκπαιδευτική εμπειρία.
