## Introduction

Ονομάζομαι <b>Στεφανίδης Μάριος</b> και είμαι απόφοιτος του Τμήματος Μηχανικών Ηλεκτρονικών Υπολογιστών και Πληροφορικής του Πανεπιστημίου Πατρών (CEID). Τα τελευταία 2,5 χρόνια εργάζομαι ως Software Engineer σε ιδιωτική εταιρεία, ενώ το τελευταίο διάστημα έχω αναλάβει ρόλο Lead Frontend Engineer σε ένα enterprise-scale project. Μέσα από την εμπειρία μου στον σχεδιασμό και την ανάπτυξη διεπαφών χρήστη, συνειδητοποίησα πόσο καθοριστική αποτελεί η αλληλεπίδραση του ανθρώπου με την τεχνολογία – όχι μόνο σε επίπεδο λειτουργικότητας, αλλά και εμπειρίας, συναισθήματος και γνωστικής προσπάθειας.

Η απόφασή μου να παρακολουθήσω το Μεταπτυχιακό στη <b>Διάδραση Ανθρώπου–Υπολογιστή (HCI)</b> προέκυψε τόσο από επαγγελματικά κίνητρα, όσο και από προσωπικό ενδιαφέρον. Αφενός, θέλω να εξελιχθώ πάνω στο αντικείμενο του frontend engineering και του UI/UX (User Interface/User Experience), διευρύνοντας τα hard skills μου αλλά και αποκτώντας βαθύτερη κατανόηση των αρχών που καθορίζουν μια καλή εμπειρία χρήστη. Αφετέρου, πάντα με ενδιέφερε ο τρόπος που λειτουργεί ο ανθρώπινος νους – πώς αντιλαμβανόμαστε, θυμόμαστε, αποφασίζουμε και αλληλεπιδρούμε με το περιβάλλον μας. Ο συνδυασμός τεχνολογίας, γνωσιακής ψυχολογίας και έρευνας που προσφέρει το HCI, καθιστά το τελευταίο το πιο ταιριαστό πεδίο για την εξέλιξή μου.

#### Τι είναι ο άνθρωπος;

Ο άνθρωπος είναι ένα ον που σκέφτεται, αισθάνεται και δημιουργεί. Προσπαθεί να κατανοήσει τον κόσμο γύρω του και να του δώσει νόημα μέσα από τη γνώση, τη δράση και τη σχέση του με τους άλλους.

#### Τι είναι ο υπολογιστής;

Ο υπολογιστής είναι μια συσκευή που δέχεται πληροφορίες, τις επεξεργάζεται και παράγει αποτελέσματα. Αποτελείται από δύο κύρια μέρη: το hardware, δηλαδή τα φυσικά μέρη του (όπως ο επεξεργαστής, η μνήμη και οι συσκευές εισόδου/εξόδου), και το software, δηλαδή τα προγράμματα που καθοδηγούν τον υπολογιστή πώς να εκτελεί τις εργασίες του.

#### Τι είναι η διάδραση ανθρώπου-υπολογιστή

Η διάδραση ανθρώπου–υπολογιστή (Human–Computer Interaction, HCI) είναι η μελέτη και ο σχεδιασμός του τρόπου με τον οποίο οι άνθρωποι χρησιμοποιούν και επικοινωνούν με τους υπολογιστές και τα ψηφιακά συστήματα. Στόχος της είναι να καταστήσει τη χρήση των υπολογιστών εύκολη, αποδοτική και παράλληλα ευχάριστη για τον άνθρωπο.

#### Ποια είναι μια αναλογία για τον υπολογιστή πέρα από εργαλείο;

Ο υπολογιστής είναι σαν ένας συνεργάτης που ακολουθεί τις οδηγίες σου, επεξεργάζεται μεγάλες ποσότητες πληροφοριών και σε βοηθά να ολοκληρώνεις σύνθετες εργασίες πιο γρήγορα, αποτελεσματικά και με μεγαλύτερη ακρίβεια.

## Γραμμή Εντολών (Arch Linux)

Για την εγκατάσταση Arch Linux σε VMWare ακολούθησα τα παρακάτω βήματα:

- Boot από το Arch Linux ISO

  ```
  # Έλεγχος σύνδεσης δικτύου
  ping -c 3 archlinux.org

  # Συγχρονισμός ρολογιού συστήματος
  timedatectl set-ntp true
  ```

- Διαμόρφωση Δίσκου

  ```
  # Προβολή διαθέσιμων δίσκων
  fdisk -l

  # Δημιουργία partitions
  fdisk /dev/sda
  ```

  Εντός του fdisk

  1. g - Δημιουργία νέου GPT partition table
  2. n - Νέο partition για EFI (π.χ. 512M)
  3. t - Αλλαγή τύπου σε EFI System (1)
  4. n - Νέο partition για root (υπόλοιπος χώρος)
  5. w - Αποθήκευση

  ```
  # Format partitions
  mkfs.fat -F32 /dev/sda1 # EFI partition
  mkfs.ext4 /dev/sda2 # Root partition

  # Mount filesystems
  mount /dev/sda2 /mnt
  mkdir -p /mnt/boot
  mount /dev/sda1 /mnt/boot
  ```

- Εγκατάσταση Βασικού Συστήματος

  ```
  # Εγκατάσταση βασικών πακέτων
  pacstrap /mnt base linux linux-firmware
  ```

- Διαμόρφωση Συστήματος

  ```
  # Δημιουργία fstab
  genfstab -U /mnt >> /mnt/etc/fstab

  # Chroot στο νέο σύστημα
  arch-chroot /mnt
  ```

- Ρυθμίσεις Βασικού Συστήματος

  ```
  # Ορισμός timezone
  ln -sf /usr/share/zoneinfo/Europe/Athens /etc/localtime
  hwclock --systohc

  # Εγκατάσταση απαραίτητων πακέτων
  pacman -S nano vim networkmanager grub efibootmgr

  # Διαμόρφωση locale
  nano /etc/locale.gen

  locale-gen

  echo "LANG=en_US.UTF-8" > /etc/locale.conf

  # Ορισμός hostname
  echo "1067458" > /etc/hostname

  # Διαμόρφωση /etc/hosts
  nano /etc/hosts
  ```

  Περιέχομενο /etc/hosts:

  ```
  127.0.0.1   localhost
  ::1         localhost
  127.0.1.1   1067458.localdomain 1067458
  ```

- Χρήστες και Κωδικοί

  ```
  # Ορισμός κωδικού root
  passwd

  # Δημιουργία χρήστη
  useradd -m -G wheel -s /bin/bash <username>
  passwd <username>

  # Ενεργοποίηση sudo για wheel group
  EDITOR=nano visudo
  ```

- Εγκατάσταση Bootloader

  ```
  # Εγκατάσταση GRUB για UEFI
  grub-install --target=x86_64-efi --efi-directory=/boot --bootloader-id=GRUB

  # Δημιουργία GRUB configuration
  grub-mkconfig -o /boot/grub/grub.cfg
  ```

- Ενεργοποίηση Υπηρεσιών

  ```
  # Ενεργοποίηση NetworkManager
  systemctl enable NetworkMamager
  ```

- Ολοκλήρωση Εγκατάστασης

  ```
  # Έξοδος από chroot
  exit

  # Unmount partitions
  unmount -R /mnt

  # Επανεκκίνηση
  reboot
  ```

Μετά την ολοκλήρωση της εγκατάστασης εκτέλεσα τις εξής εντολής προκειμένου να δημιουργήσω τα παραδοτέα της άσκησης και το ζητούμενο [recording](https://asciinema.org/a/jWhEtznf8YjU4ADmGQlJm7kGG).

```

pacman -Syu

# Εγκατάσταση του asciinema για καταγραφή terminal sessions
pacman -S asciinema

# Εγκατάσταση του fastfetch για εμφάνιση πληροφοριών συστήματος

```

## Συμμετοχικό Περιεχόμενο 1Α

### Figures

Για την εβδομάδα 4 επέλεξα να προσθέσω στο βιβλίο 2 εικόνες με βάση το παρακάτω θέμα που ορίστηκε.

<b>"Η Εξέλιξη των Συσκευών Εισόδου: Από το Ποντίκι στο Άγγιγμα και τη Χειρονομία"</b>

Έχοντας υπόψιν τη γραμμική εξέλιξη από το ποντίκι στο touchscreen, θεώρησα πως περισσότερο ενδιαφέρον να εστιάσω σε συσκευές που απέτυχαν πρόωρα — μιας και οι αποτυχίες μάς διδάσκουν περισσότερα για το πώς η τεχνολογία συναντά την ανθρώπινη συμπεριφορά.

- <b>Nintendo Power Glove (1989):</b> Το γάντι που ήθελε να γίνει το μέλλον — και απέτυχε θεαματικά

![Power Glove](https://upload.wikimedia.org/wikipedia/commons/d/d3/NES-Power-Glove.jpg)

Το Power Glove κυκλοφόρησε το 1989 από τη Mattel για το Nintendo Entertainment System, βασισμένο στην τεχνολογία του VPL DataGlove των $10,000. Χρησιμοποιούσε οπτικές ίνες στα δάχτυλα που ανιχνεύαν τέσσερις θέσεις ανά δάχτυλο, αλλά η ακρίβειά του ήταν εξαιρετικά χαμηλή. Παρά τις περίπου ένα εκατομμύριο πωλήσεις, το προϊόν απέτυχε λόγω των εξαιρετικά δύσχρηστων χειριστηρίων. Εξετάζει πώς το "too early" φαινόμενο και η φτηνή υλοποίηση μιας καινοτόμου ιδέας μπορεί να καταστρέψει την υπόσχεση της.

- <b>Light Pen (1950s-1980s):</b> Το πρώτο touchscreen που κούραζε τα χέρια μας

![Light Pen](https://upload.wikimedia.org/wikipedia/commons/c/cd/HypertextEditingSystemConsoleBrownUniv1969.jpg)

Το light pen δημιουργήθηκε γύρω στο 1951-1955 ως μέρος του έργου Whirlwind I στο MIT και χρησιμοποιήθηκε στο σύστημα SAGE για στρατιωτική επιτήρηση του εναέριου χώρου. Στη δεκαετία του 1960, τα light pens ήταν συνηθισμένα σε γραφικά τερματικά όπως το IBM 2250. Ωστόσο, επειδή ο χρήστης έπρεπε να κρατά το χέρι του μπροστά στην οθόνη για μεγάλα χρονικά διαστήματα (προκαλώντας "gorilla arm"), το light pen έπεσε σε αχρησία. Η ιδέα παρουσιάζει πώς η εργονομία είναι εξίσου σημαντική με την τεχνολογική καινοτομία.

### Slides

Όσον αφορά στα slides, αποφάσισα να παρουσιάσω τη χρονολογική εξέλιξη των συσκευών εισόδου, εστιάζοντας στη σταδιακή μετάβαση από την άμεση επαφή με την οθόνη προς την έμμεση φυσική αλληλεπίδραση με το χώρο.

- HP 150 Touchscreen (1983): Αποτελεί την πρώτη εμπορική υλοποίηση της οθόνης αφής, προσεγγίζοντας ακόμη περισσότερο τη φυσική κίνηση του ανθρώπου.
- Nintendo Power Glove (1989): Αντιπροσωπεύει την ολοκληρωτική απελευθέρωση από την οθόνη, ένα ριζικό άλμα. Πλέον, η χειρονομία σημαίνει εισαγωγή δεδομένων.
- Microsoft Surface Table (2007): Επαναπροσδιορίζει την αφή σε πολύ-χρηστική, συνεργατική διεπαφή, όπου πολλοί μπορούν να αλληλεπιδρούν ταυτόχρονα.
- Kinect (2010): Αποτελεί την κορύφωση αυτής της πορείας, δηλαδή απουσία αγγίγματος και εργαλείων. Πλέον, το ανθρώπινο σώμα και οι χειρονομίες του στον τρισδιάστατο χώρο αρκούν για την αλληλεπίδραση.

## Γραμμή εντολών (Custom Desktop Environment)

Αρχικά, ολοκλήρωσα την εγκατάσταση του i3 εκτελώντας τις ακόλουθες εντολές

```bash
# Ενημέρωση Συστήματος
pacman -Syu

# Εγκατάσταση i3
pacman -S i3-wm i3status i3lock dmenu
```

Το i3-wm είναι ο window manager, το i3status για το status bar, το i3lock για το screen locking, και το dmenu για launcher εφαρμογών.

Έπειτα, εγκατέστησα τα εξής:

2. Terminal Emulator

```bash
pacman -S alacritty
```

και προχώρησα με τις κατάλληλες ρυθμίσεις ώστε να ξεκινάει το i3

```bash
echo "exec i3" > ~/.xinitrc
```

#### Προσαρμογες στο i3

- Προσθήκες και αλλαγές στο <b>~/.config/i3/config</b>

  ```bash
  # Όρισα το terminal
  set $term alacritty
  bindsym $mod+Return exec $term

  # Πρόσθεσα launcher rofi)
  bindsym $mod+d exec rofi -show drun
  ```

- Εγκατάσταση <b>i3blocks</b> για καλύτερο status bar

  ```bash
  pacman -S i3blocks

  # Δημιούργησα config για i3blocks
  mkdir -p ~/.config/i3blocks
  cp /etc/i3blocks.conf ~/.config/i3blocks/config
  ```

  - Ενεργοποίηση i3blocks στο i3 config (~/.config/i3/config) και αλλαγή της γραμμής "bar {" με

    ```bash
    bar {
      status_command i3blocks
    }
    ```

#### Εξατομίκευση i3

- Color Theme (Solarized)

  Προσθήκη στο τέλος του αρχείου ~/.config/i3/config

  ```bash
  # Solarized Dark colors
  set $base03    #002b36
  set $base02    #073642
  set $base01    #586e75
  set $base00    #657b83
  set $base0     #839496
  set $base1     #93a1a1
  set $base2     #eee8d5
  set $base3     #fdf6e3
  set $yellow    #b58900
  set $orange    #cb4b16
  set $red       #dc322f
  set $magenta   #d33682
  set $violet    #6c71c4
  set $blue      #268bd2
  set $cyan      #2aa198
  set $green     #859900

  # Window colors
  #                       border     background text       indicator
  client.focused          $blue      $blue      $base3     $blue
  client.focused_inactive $base02    $base02    $base1     $base02
  client.unfocused        $base02    $base02    $base01    $base02
  client.urgent           $red       $red       $base3     $red

  # Bar colors
  bar {
      status_command i3blocks
      position top

      colors {
          background $base03
          statusline $base1
          separator  $base01

          #                  border     background text
          focused_workspace  $blue      $blue      $base3
          active_workspace   $base02    $base02    $base1
          inactive_workspace $base03    $base03    $base01
          urgent_workspace   $red       $red       $base3
      }
  }
  ```

- Status Bar (i3blocks) με custom modules

  Δημιούργησα custom config

  ```bash
  mkdir -p ~/.config/i3blocks
  nano ~/.config/i3blocks/config
  ```

  και πρόσθεσα

  ```bash
  [time]
  command=date '+%H:%M:%S'
  interval=1
  color=#2aa198

  [date]
  command=date '+%Y-%m-%d'
  interval=60
  color=#268bd2

  [battery]
  command=acpi | grep -oP '\d+(?=%)'
  interval=30
  label=BAT:
  color=#859900

  [volume]
  command=amixer get Master | grep -oP '\d+(?=%)' | head -1
  interval=5
  label=SOUND:
  color=#b58900

  [memory]
  command=free -h | awk '/^Mem:/ {print $3 "/" $2}'
  interval=10
  label=MEM:
  color=#d33682

  [cpu]
  command=top -bn1 | grep "Cpu(s)" | awk '{print $2}' | cut -d'%' -f1
  interval=5
  label=CPU:
  color=#dc322f

  [disk]
  command=df -h / | awk 'NR==2 {print $3 "/" $2}'
  interval=30
  label=DISK:
  color=#6c71c4
  ```

- Wallpaper

  Εγκατάσταση feh (για wallpaper)

  ```bash
  pacman -S feh
  ```

  Κατέβασμα wallpaper

  ```bash
  mkdir -p ~/Pictures/wallpapers
  cd ~/Pictures/wallpapers
  # Κατέβασμα κάποιου wallpaper
  curl -o wallpaper.jpg "URL_του_wallpaper"
  ```

  Ρύθμιση στο i3 config (nano ~/.config/i3/config)

  ```bash
  # Wallpaper
  exec_always --no-startup-id feh --bg-scale ~/Pictures/wallpapers/wallpaper.jpg
  ```

  ```bash
  exec_always --no-startup-id dunst
  ```

- Screensaver & Lock

  Εγκατάσταση

  ```bash
  pacman -S xautolock i3lock
  ```

  Ρύθμιση στο i3 config

  ```bash
    # Auto lock after 10 minutes
    exec --no-startup-id xautolock -time 10 -locker 'i3lock -c 002b36'
    # Manual lock με Mod+Shift+x
    bindsym $mod+Shift+x exec i3lock -c 002b36
  ```

## Συμμετοχικό Περιεχόμενο 2Α

### Σύντομη Παρουσίαση Case Study - Apple Newton MessagePad

Το case study για το Apple Newton MessagePad εξετάζει μια πρώιμη προσπάθεια φυσικής διάδρασης μέσω γραφίδας και αναγνώρισης χειρόγραφου. Το Newton παρουσιάζεται ως χαρακτηριστικό παράδειγμα τεχνολογίας που εμφανίστηκε "πολύ νωρίς" με υψηλή φιλοδοξία αλλά περιορισμένη τεχνολογική ωριμότητα. Το κείμενο αναδεικνύει πώς η ατελής αναγνώριση χειρογράφου μετέτρεψε μια φαινομενικά φυσική διεπαφή σε απαιτητική διαδικασία για τον χρήστη, προσφέροντας κατά αυτό τον τρόπο ένα χρήσιμο μάθημα για την εργονομία και την αξιοπιστία των συσκευών εισόδου.

Η βιβλιογραφία που χρησιμοποιήθηκε, περιλαμβάνει έργα των Isaacson, Smith και Norman, τα οποία καλύπτουν το ιστορικό, τεχνικό και ψυχολογικό πλαίσιο, επιτρέποντας την ένταξη του Newton στη μεγαλύτερη αφήγηση για την εξέλιξη της διάδρασης.

### Σύντομη Παρουίαση Βιογραφίας - Bill Buxton

Η βιογραφία του Bill Buxton παρουσιάζει τον ερευνητή που διαμόρφωσε θεμελιώδεις αρχές της σύγχρονης διάδρασης, τονίζοντας τη σύνδεση μεταξύ ανθρώπινης κίνησης, απτικότητας και εργονομίας. Ο Buxton ανέλυσε πως οι συσκευές εισόδου πρέπει να στηρίζονται στις φυσικές δεξιότητες του ανθρώπου και όχι να τον αναγκάζουν να προσαρμοστεί σε αυτές. Η δουλειά του στη Xerox PARC και στη Microsoft Research επηρέασε καθοριστικά το stylus input, το pen+touch, αλλά και τις χειρονομιακές διεπαφές.

Η βιβλιογραφία βασίζεται σε έργα του ίδιου του Buxton και συναδέλφων του, με έμφαση στο Sketching User Experiences και σε άρθρα για τα πρότυπα συσκευών εισόδου και τα μοντέλα χειρονομιών.

### Πώς συνδέονται με τα προηγούμενα (timeline, figures, slides, gallery)

Τα δύο νέα στοιχεία (case study & biography) εντάσσονται οργανικά στη θεματική εξέλιξη των συσκευών εισόδου.

- Το Newton λειτουργεί ως ενδιάμεσο στάδιο ανάμεσα στις πρώιμες συσκευές άμεσης επαφής (Light Pen, stylus tablets) και τις μεταγενέστερες gesture-based διεπαφές (Power Glove, Kinect).
- O Bill Buxton συνδέει θεωρητικά όλα αυτά τα παραδείγματα. Πιο συγκεκριμένα, η έρευνά του εξηγεί:
  - γιατί μερικές συσκευές πέτυχαν ενώ άλλες απέτυχαν
  - τι σημαίνει "σωστή" χειρονομία
  - πως η απτικότητα, ο χρόνος απόκρισης και η εργονομία καθορίζουν την υποκειμενική ευχρηστία

Ουσιαστικά προσφέρει το θεωρητικό πλαίσιο που "δένεται" με τις αποτυχίες του Power Glove, τα προβλήματα του Light Pen αλλά και την επιτυχία των multitouch συσκευών.
